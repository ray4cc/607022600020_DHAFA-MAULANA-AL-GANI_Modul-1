C. Contoh Study Case (Dibimbing Asprak)

Studi Kasus: Sebuah pabrik tekstil membutuhkan kalkulator untuk menghitung sisa potongan kain. Jika 1
roll kain panjangnya 50.5 meter, dan hari ini terpakai 12.2 meter, buatlah program untuk menghitung
sisa kain dan menampilkannya.

D. Soal / Latihan (Waktu: 3 Hari)

1. Soal Cerita (Kalkulasi Gaji): Seorang karyawan lepas dibayar Rp 50.000 per jam. Buatlah program
yang meminta input jumlah jam kerja, lalu hitung total gajinya. Tampilkan gajinya!
2. Soal Cerita (Konversi Suhu Mesin): Mesin oven industri menampilkan suhu dalam Fahrenheit.
Buatlah program yang meminta input Fahrenheit dan mengubahnya ke Celcius (C = (F - 32) * 5/9).
Gunakan tipe data float!

Debugging: Diberikan kode untuk menghitung rata-rata nilai 3 sensor. Outputnya selalu salah (tidak ada
desimal). Perbaiki kodenya!
int s1 = 81, s2 = 85, s3 = 90;
float rata = (s1 + s2 + s3) / 3;
